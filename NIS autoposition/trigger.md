## 트리거로 쓸 것

### 종료 판정 (권장)

1. **크기 증가 이벤트**: nd2 크기가 사전 할당 플래토 값에서 벗어나 커지면 "푸터 쓰기 시작" 으로 본다.
   촬영 중에는 크기가 절대 변하지 않으므로 오탐 가능성이 가장 낮은 신호다.
2. **그 뒤 mtime 정지 확인**: 크기 증가가 관찰된 뒤 mtime 이 3초 이상 갱신되지 않으면 완료로 확정.
   푸터 쓰기 자체는 약 1.5초 안에 끝났고, 그 이후로는 mtime 이 다시는 바뀌지 않았다.

즉, `size > plateau_size` 가 된 시점부터 mtime 무변화 3초 = 촬영 완료.

### 보조/안전장치

- **mtime 침묵 타임아웃**: 크기 증가를 놓치는 경우를 대비해 mtime 이 15초 이상 안 바뀌면 완료로 간주.
  촬영 중 정상 정지 구간이 5~6초까지 있었으므로 임계값은 10초 미만으로 잡으면 안 된다.
- **폴더 mtime / 새 파일 등장** 은 "촬영 시작" 신호로만 쓴다. 시작 후 약 2초 뒤 크기가 사전 할당값으로 점프하므로,
  플래토 값은 "생성 후 첫 크기 점프가 끝난 뒤 크기가 고정된 값" 으로 런타임에 잡으면 된다 (하드코딩 금지, 실험 크기마다 다름).

### 구현 스케치

```
상태: WAIT_FILE -> PREALLOC -> CAPTURING -> FINALIZING -> DONE
WAIT_FILE : 새 .nd2 등장 → PREALLOC
PREALLOC  : 크기가 1초 이상 고정되면 plateau = size → CAPTURING
CAPTURING : size > plateau 관측 → FINALIZING
            (또는 mtime 무변화 15초 → DONE, 로그에 '타임아웃 종료' 표시)
FINALIZING: mtime 무변화 3초 → DONE
```
